# 无极军团模型路由

> 当前可用模型来自 DSH settings 实际配置，不虚构 Luna/Earth 路由。

| 角色/阶段 | 首选 | 回退 | 说明 |
|---|---|---|---|
| 阿极 | `gpt/gpt-5.6` | `hubway/deepseek-v4-flash` | 需求收集、澄清、汇报；相对轻量 |
| 参谋部 | `gpt/gpt-5.6-sol` | `gpt/gpt-5.6-terra` | 复杂分析、拆 DAG、依赖和重规划 |
| 普通执行 | `hubway/deepseek-v4-flash` | `gpt/gpt-5.6` | 机械/低难度任务 |
| 高难执行 | `gpt/gpt-5.6-sol` | `hubway/deepseek-v4-pro` | 高推理、复杂代码和高风险任务 |
| 视觉 | 原生支持图片的当前模型 | ModLens 3.20.0 | 当前模型支持图片则直通，否则视觉旁路 |

## 路由规则

1. 简单任务不启动参谋部慢路径。
2. 阿极不做全局分析，只收集和澄清。
3. 参谋部是唯一全局调度者。
4. 主帅只做域内选型。
5. 执行模型按任务难度选择。
6. 当前 settings 未发现 Luna/Earth 的有效 provider/model，不配置虚构名称；以后发现真实 provider 后再加入候选。
7. 模型能力以 DSH `llm.resolveModelInfo()` 的实际结果为准，不以名称猜测。
