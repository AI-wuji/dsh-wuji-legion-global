## 四、风险与边界（铁律六）

1. **改了 web profile 的 patch**——这是用户正在运行的 harness 配置。DSH 重启后插件生效；若插件加载失败，DSH 会报错（patch 引用了未安装的包会 fail），但我们的包已安装、逻辑已验证，失败风险低。
2. **未跑 pnpm install**——包装是手动复制进 node_modules，不是 pnpm 依赖树的一部分。若 DSH 重启时清 node_modules，包装会丢。后续应把包加入 profile 的 package.json 依赖（或文档说明重装方式）。
