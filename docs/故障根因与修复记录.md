# 故障根因与修复记录

## 重启后历史加载失败

**现象**：

```text
历史加载失败：history unavailable ...
Invalid element at key "task": expected a Zod schema (internal)
```

**根因**：`packages/wuji-host/lib/observability.js` 中 `telemetrySchema` 把 `task` 的字段对象直接放进 `z.object()`：

```js
z.object({ task: { pending: z.number(), ... } })
```

Zod 要求每个字段值本身是 Schema。正确写法是：

```js
z.object({ task: z.object({ pending: z.number(), ... }) })
```

**为什么反复出现**：WorkBuddy 曾经修复过已安装 profile 副本，但仓库源文件没有永久修复；下一次安装/重启又把错误源文件复制回去。

**永久修复**：

1. 修复仓库源文件。
2. 将修复包重新安装到 DSH Desktop 的 `profiles/desktop`。
3. 新增 `packages/wuji-host/test/cold-restore.test.js`，逐一初始化、view、Schema parse、checkpoint 验证六个 projection。
4. 冷恢复测试通过：

```text
cold restore projection schemas OK wuji.requirement,wuji.task,wuji.officer-advice,wuji.memory,wuji.evolution,wuji.telemetry
```

以后修改 projection schema，必须同时运行冷恢复回归测试，不能只运行热路径工具测试。
