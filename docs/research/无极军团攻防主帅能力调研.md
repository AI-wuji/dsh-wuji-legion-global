# 无极军团 · 攻防主帅能力调研（破译 + 加密，攻防一体）

> 版本：v1.0
> 日期：2026-08-15
> 触发：用户提出需要"黑客主帅"——破译闭源插件原理/元指令（借鉴用），同时加密自己的产出物（防破译）。
> 白帽边界：破译用于"借鉴原理/互操作性/安全研究"合理，用于盗版/破解牟利/绕过授权违法；加密自己产出物正当。能力需带使用边界。

---

## 一、破译/逆向（攻）—— 官方/高星背书

| 能力 | 官方/高星 | 机制 | 用途 |
|---|---|---|---|
| [Google CASCADE（ICSE 2026）](https://arxiv.org/abs/2507.17691) | **Google 官方 + ICSE 2026** | LLM 驱动的 JavaScript 反混淆器（VM bytecode + control-flow flattening） | **破译 JS 插件原理**（最高背书） |
| [LLM4Decompile](https://github.com/albertan017/LLM4Decompile) | 社区高星（有 benchmark） | 用 LLM 反编译二进制代码 | 破译编译后的二进制插件 |
| [kong（agentic reverse engineer）](https://github.com/amruth-sn/kong) | 社区项目 | "世界首个 agentic 逆向工程师" | agent 化逆向 |
| [deobfuscation-mcp（IDA Pro）](https://github.com/zhizhuodemao/deobfuscation-mcp) | 社区 | MCP Server 接 IDA Pro，反混淆+打补丁 | 专业逆向工具接入 |
| [RAVERSE（多 agent 二进制修补）](https://github.com/usemanusai/jaegis-RAVERSE) | 社区 | AI 多 agent 二进制修补系统（35 工具） | 二进制分析与修补 |

**关键**：CASCADE（Google 官方）+ LLM4Decompile 是"破译代码原理"的最强背书——LLM 确实能反混淆/反编译。

## 二、加密/保护（防）—— 官方/高星背书

| 能力 | 官方/高星 | 机制 | 用途 |
|---|---|---|---|
| [ProxyPrompt（博世研究院）](https://github.com/boschresearch/proxyprompt) | **博世官方（论文）** | 保护系统提示词（元指令）不被提取 | **加密元指令**（防止破译 prompt） |
| [CaMeL（DeepMind）](https://cloud.tencent.cn/developer/article/2521013) | **DeepMind 官方** | 抵御 LLM 提示词注入 | 元指令注入防御 |
| [quantum-shield-obfuscator](https://github.com/sunmughan/quantum-shield-obfuscator) | 社区 | AES-256 加密 + 反调试 + 多层保护 | 代码混淆加密 |
| [javascript-obfuscator（生态）](https://javascriptobfuscator.com/) | 生态高星 | JS 混淆（控制流扁平化等） | 代码保护 |

**关键**：元指令（prompt）保护有博世 ProxyPrompt + DeepMind CaMeL 官方背书；代码加密有成熟混淆器。

## 三、攻防一体的核心洞察

1. **会攻才更会防**：Google 的 CASCADE（攻）+ 博世 ProxyPrompt（防）是一体两面——懂反混淆原理，才知道怎么混淆得更难被反混淆。
2. **攻防是同一能力域**：破译和加密不该分成两个主帅，应该是**同一个"攻防主帅"的两个方向**（攻=逆向借鉴，防=加密保护）。
3. **官方背书齐全**：攻有 Google CASCADE，防有博世 ProxyPrompt + DeepMind CaMeL——都不是臆断。

---

## 四、对规划的建议

1. **增设"攻防主帅"**（或归入安全主帅的能力域），管两个方向：
   - **攻（逆向借鉴）**：破译闭源插件原理/元指令——用于"借鉴"（合法边界内）。
   - **防（加密保护）**：加密自己的产出物（代码混淆 + 元指令保护）——防被破译。
2. **能力清单**：
   - 攻：CASCADE（Google，反混淆 JS）+ LLM4Decompile（反编译）+ deobfuscation-mcp（IDA 接入）
   - 防：ProxyPrompt（博世，元指令保护）+ CaMeL（DeepMind，注入防御）+ 混淆器
3. **白帽边界写入主帅职责**：破译限"借鉴原理/互操作性/安全研究"，禁止盗版/破解牟利/绕过授权；加密是正当权利。

---

## 五、白帽的补充提醒

1. **攻防主帅必须有明确的合法边界**：逆向借鉴 vs 盗版破解的界限要写死，防止被滥用。
2. **加密不是万能的**：混淆/加密只是提高门槛，不是绝对安全（CASCADE 证明 LLM 能反混淆 JS）。**真正的保护是"不泄露关键逻辑"（把核心放服务端）+ 加密（提高门槛）双管齐下**。
3. **元指令保护尤其重要**：我们的元指令（prompt）是核心竞争力，博世 ProxyPrompt + DeepMind CaMeL 的防护要优先用上。
