## 一、事件背景

- **事件**：Anthropic 构建失误，Claude Code 完整源码（约 51.2 万行 TypeScript，1900+ 文件）意外泄露（2026 年）。
- **社区反应**：已有人逆向工程，整理成 [awesome-cc-harness](https://github.com/WanLanglin/-awesome-cc-harness)（agent loop / 工具系统 / 权限模型 / Grove 训练管线 / 反蒸馏防御）、[claude-code-source-analysis](https://github.com/jiahp0920/claude-code-source-analysis)（18 模块可视化架构）等分析。
- **白帽立场**：这是 Anthropic 的失误泄露，不是我们主动破解；我们只**借鉴设计思想**（架构、机制、prompt 结构），**不复制其代码**，不触碰其未发布功能。

## 二、泄露源码揭示的关键设计（可借鉴项）

逆向分析揭示的 5 个 Agent 设计模式 + 几个内部机制：

| 泄露内容 | 机制 | 对无极军团的启发 |
|---|---|---|
| **权限模型（6 级安全架构）** | 分级权限：只读 / 写工作区 / 写全局 / 网络 / 执行命令 / 全权 | **保卫科/最小权限的具体分级**——比我们"restrict"更细的权限分级可借鉴 |
| **反蒸馏防御（anti-distillation）** | 检测针对中国用户的隐藏代码（后因信任危机回滚） | **白帽警示**：这种"隐藏检测"是错误示范，我们绝不学；但它提醒"产出物加密"的必要性（攻防主帅的防方向） |
| **Speculation 预判执行系统** | AI 偷偷预判用户下一步、提前执行 | **直道优先的极致**：预判+提前执行可大幅提速（但需谨慎，白帽见下） |
| **Skills 系统全链路** | 技能如何学习用户工作流 | 与我们"进化主帅蒸馏工作流成技能"同向，可对照其实现 |
| **26 个隐藏指令** | 内部 prompt 指令 | 参考其 prompt 结构设计（但不抄） |

## 三、最有价值的可借鉴项（白帽判断）

### 1. 权限模型（6 级安全架构）—— 直接补强保卫科

Claude Code 的分级权限模型，比我们现在的"最小权限 restrict"更细：
```
只读 → 写工作区 → 写全局 → 网络 → 执行命令 → 全权
```
**启发**：无极军团的子 agent 权限，应按这个 6 级分级，而不是一刀切"最小权限"。安全主帅/保卫科据此分级授权。

### 2. Skills 系统全链路 —— 对照我们的进化主帅

泄露揭示 Claude Code 如何"学习用户工作流成技能"——这与我们的"进化主帅蒸馏工作流成技能"是同一件事。可对照其实现细节，改进我们的进化闭环。

### 3. Speculation 预判执行 —— 直道优先的极致（但要白帽把关）

Claude Code 会"预判用户下一步提前执行"。这能提速，但**白帽必须警示**：
- 预判执行有风险（猜错 = 白干甚至出错）
- 只适合"高置信度、低风险、可回滚"的场景
- 无极军团可借鉴"预判"思想，但必须**前置限制**（预判动作也要过守卫 + 可回滚）

### 4. 反蒸馏防御的教训（反面教材 + 正面启示）

- **反面**：Claude Code 的"隐藏检测针对中国用户"被曝光后引发信任危机、被迫回滚——这是**错误示范**，无极军团绝不搞"隐藏检测/后门"。
- **正面**：它提醒我们"产出物加密/反蒸馏"是真实需求——攻防主帅的"防"方向（博世 ProxyPrompt + DeepMind CaMeL）更该重视。

## 四、白帽的完整立场（重要）

1. **我们只借鉴设计思想，不复制代码**：泄露是 Anthropic 的失误，复制其代码有法律风险，且违背我们的"独立体系"原则。
2. **绝不学"隐藏检测/后门"**：Claude Code 的隐藏检测是反面教材，无极军团必须透明、可审计。
3. **借鉴定位于"设计模式"**：权限分级、skills 系统、工具 hook、prompt 结构——这些是通用设计思想，任何 agent 系统都有，借鉴无问题。
4. **攻防主帅的合法性**：反蒸馏/加密产出物是正当需求（保护自己的元指令），但"破译别人闭源"要守边界（只借鉴原理、不盗版破解）。

---

## 五、对规划的增量建议

1. **保卫科/安全主帅的权限分级**：采用 6 级权限模型（只读→写工作区→写全局→网络→执行命令→全权），比"最小权限"更细。
2. **进化主帅对照 Skills 系统**：参考 Claude Code 如何学习工作流成技能，改进进化闭环。
3. **Speculation 预判执行（谨慎借鉴）**：只在高置信度+低风险+可回滚场景用，且预判动作也要过守卫。
4. **攻防主帅的"防"方向强化**：反蒸馏/元指令加密是真实需求，ProxyPrompt/CaMeL 更该重视。
