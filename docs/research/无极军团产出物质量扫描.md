## 六、核心结论（五类产出物的质量关键）

| 产出物 | 质量关键 | 对我们的印证 |
|---|---|---|
| PPT | 可编辑 native-PPTX > 不可编辑 HTML；选型看"是否要可编辑" | 印证"PPT 做可编辑" |
| 文案 | "人味"（去 AI 味） | 印证"人味改稿" |
| 元指令 | "工程级"（结构+边界+可测试） | 印证"五段式"，补"可测试" |
| ComfyUI 插件 | 跟随官方 schema 演进 | 印证"遵循官方规范"，补"持续跟进" |
| 软件开发 | 调度模型决定质量；防 code smell | 印证"参谋部最高智商"+ "规范精简重构" |

## 七、对规划的增量建议

1. **PPT 选型依据明确**：可编辑需求 → native-PPTX；快速预览 → HTML（many-ppt-skills 对比）。
2. **文案主帅加"人味"能力**：去 AI 味、加人味（khazix-writer 方向）。
3. **元指令加"可测试"**：五段式之外，元指令也要有验收/测试（工程级）。
4. **开发主帅加"code smell"检查**：不只"能跑"，还要"无坏味道"（SmellBench）。
5. **"调度模型决定质量"**：印证参谋部用最高智商，开发主帅的选型/架构判断比执行更关键（ADK Arena）。
