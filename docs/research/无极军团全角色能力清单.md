# 无极军团 · 全角色能力清单（官方/高星背书）

> 版本：v1.0
> 日期：2026-08-15
> 性质：为**所有角色**（阿极、参谋部、白帽、独立官员、各级主帅）逐一找到"官方或高星/近期增长快"的已验证能力。**原则：只用官方出品 或 GitHub 高星/有 benchmark 的能力，不用臆断。**

## 五、关键结论（数据说话）

1. **所有角色都有官方或高星背书的能力，无空白**：
   - 白帽 → Anthropic Persona Vectors（官方）+ OpenAI sycophancy 声明（官方）
   - 阿极 → Google Learning to Clarify（官方）+ Anthropic Cookbook（官方）
   - 参谋部 → OpenAI Agents SDK（官方）+ Anthropic subagents（官方）
   - 根因 → Microsoft OpenRCA（官方+ICLR）
   - 审计 → Facebook secpriv（官方+benchmark）
   - 保卫科 → OWASP（官方）+ GitHub（官方）
   - 各级主帅 → 见上表（各有 benchmark/star/官方背书）

2. **"验证"有官方/权威标准**：TRACE（腾讯+实验室）、secpriv 128-case benchmark、OpenRCA benchmark、PawBench——这些是"能力入库"的真实门槛。

3. **关键洞察**：
   - **防迎合有官方解法**（Persona Vectors 可编辑掉 sycophancy）——白帽不是我们臆想的角色，是模型真实缺陷（OpenAI 官方回滚谄媚版）的对治。
   - **调度有官方范式**（OpenAI handoff + Anthropic subagents）——参谋部不是抽象概念。
   - **能力入库必须带 benchmark**（secpriv 模式）——不是 README 自吹。

---

## 六、对规划的影响

1. 每个角色（阿极/参谋部/白帽/官员/主帅）= **有官方或 benchmark 背书的能力**，不靠臆断设计。
2. 能力入库标准 = **官方/高星 + benchmark**（secpriv 模式：detector-validator + benchmark），呼应之前的"行为探针"，现在有了具体标准。
3. 参考优先级：**官方 > 高星/近期增长快 > 论文 > 社区**——只吸收前两类进无极军团。
