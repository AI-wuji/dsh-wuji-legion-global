# 浏览器与本地软件调配

## 已确定策略

| 目标 | 首选 | 备用 | 安全边界 |
|---|---|---|---|
| 浏览器 | DSH 原生 web / shell / subprocess / terminal / MCP | 经过审计的浏览器插件 | 点击、提交、下载等副作用动作按工具权限和用户授权执行 |
| ComfyUI | 本机 ComfyUI HTTP API | DSH shell 启动/检查（需明确授权） | 生成会消耗 GPU、写文件；执行前检查 endpoint 和工作流 |
| 其他桌面软件 | 官方 CLI/API/MCP | shell/subprocess/terminal | 不安装低星桌面控制插件，不用无边界模拟鼠标键盘 |

## 当前候选审计结论

- 低星 DSH 浏览器插件不直接安装。
- 已接入 Microsoft 官方 `playwright-mcp`（36K+ stars、Apache-2.0），通过 DSH MCP client 暴露为 `mcp__playwright__*` 工具；点击、填写、下载等外部副作用仍遵守权限与用户授权。
- `dsh-crew` 有多 Agent 和视觉桥接价值，但与无极参谋部重叠，暂不作为依赖。
- `modlens` 已安装，负责纯文本模型视觉旁路。
- ComfyUI 当前在线于 `127.0.0.1:8898`，四个 HTTP API 端点已验证；尚未提交真实工作流。

## 自动调配规则

```text
用户说“打开网页/操作网页”
→ 参谋部选择 browser-control
→ 检查可用 provider 和副作用
→ 调用 DSH 原生能力或已审计插件

用户说“运行 ComfyUI 工作流”
→ 参谋部选择 comfyui-control
→ 探测本机 endpoint
→ 在线则调用 HTTP API
→ 离线则报告，不自动启动软件
```
